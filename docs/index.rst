Welcome to beansp's documentation!
======================================

This software uses a Markov Chain Monte Carlo approach to match observations of thermonuclear bursts from accreting neutron stars with numerical models, to constrain parameters including the accreted fuel composition, source distance and system inclination, and neutron star mass and radius.

The code was written by Adelle Goodwin and Duncan Galloway. pySettle was
developed from the original code written by Andrew Cumming.
